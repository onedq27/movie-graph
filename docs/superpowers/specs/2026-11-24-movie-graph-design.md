## რა არის და რატომ

gemovie.tv-ის ფილმებისა და სერიალების ინტერაქტიული "მსგავსების გრაფი": ირჩევ ფილმს,
ხედავ მის ირგვლივ 10–15 ყველაზე მსგავს ფილმს (ჟანრითა და სიუჟეტით), კვანძზე დაჭერით
კითხულობ აღწერას და გადადიხარ საიტზე საყურებლად. მიზანი — "რა ვუყურო ამის მსგავსი"

## მიდგომები

სიუჟეტის მსგავსების დასათვლელად სამი გზა განვიხილეთ:

- **A. ლოკალური მრავალენოვანი embedding მოდელი** — უფასო, მონაცემი გარეთ არ გადის, ქართულს
  აზრობრივად ადარებს; ფასი: ~1–2 GB ერთჯერადი დაყენება და რამდენიმე წუთი დათვლა.
- **B. ფასიანი embedding API** — ყველაზე ზუსტი, მაგრამ ფასიანია და ტექსტები გარეთ იგზავნება.
- **C. TF-IDF (სიტყვების დამთხვევა)** — დაყენება არ სჭირდება, მაგრამ 1–2 წინადადებიან
  ქართულ აღწერებზე სუსტია (ბრუნვები/ფორმები ერთმანეთს არ ემთხვევა).

**არჩეულია A** — მომხმარებელმა თქვა "უფასო ვერსია გამოიყენე"; A და C ორივე უფასოა, A-ს ვირჩევ
(ჩემი რეკომენდაცია იყო), რადგან C პირდაპირ ეწინააღმდეგება ანტი-მიზანს "სიუჟეტით არაფერი საერთო".

მიწოდების ფორმა: **სტატიკური PWA GitHub Pages-ზე** (ჩემი გადაწყვეტილება, მომხმარებლის "აპლიკაციასავით,
ტელეფონში, GitHub-ის ლინკიდან" მოთხოვნიდან). ნეიტივ აპი (APK / App Store) უარყოფილია: ხელმოწერა,
ცალკე build-ები, iPhone-ზე ლინკიდან დაყენება შეუძლებელია. PWA ერთი ლინკია, "Add to Home Screen"-ით
ყენდება ორივე პლატფორმაზე და სერვერი არ სჭირდება, რადგან მსგავსება წინასწარაა დათვლილი.

## როგორ მუშაობს

ორი ნაწილი: (1) ერთჯერადი მონაცემთა pipeline ლოკალურად, (2) სტატიკური ვებ-აპი, რომელიც
მხოლოდ მზა JSON-ს კითხულობს.

### 1. Pipeline (Python, venv-ში)

1. **ჩამოტვირთვა** — sitemap-ებიდან ყველა ფილმისა და სერიალის URL; თითო გვერდის HTML ინახება
   ლოკალურ ქეშში. ნელა (არაუმეტეს ~3 მოთხოვნა/წმ), retry-ებით, შეწყვეტის შემდეგ გაგრძელებადი;
   განმეორებით გაშვებაზე მხოლოდ ახალი/აკლებული გვერდები.
2. **ამოღება** — ld+json-იდან: id, ტიპი (movie/serial), ქართული სახელი, ინგლისური სახელი
   (`name`-ის დაშლით), წელი (URL-იდან), ჟანრები, აღწერა, სურათის URL, გვერდის URL.
   **ჩანაწერი აღწერის გარეშე** (ჩემი გადაწყვეტილება): რჩება სიაში და ძებნადია, მაგრამ სხვა
   ფილმების მეზობლად არასდროს ჩნდება. მის საკუთარ გრაფში მეზობლები მხოლოდ ჟანრით ირჩევა
   (ჟანრების Jaccard, ცალკე სკალა) და აპი ამას აშკარად აწერს: "აღწერა არ არის — კავშირები
   მხოლოდ ჟანრითაა". ექსპორტში ასეთ ჩანაწერს აქვს ნიშანი. pipeline ბოლოს ბეჭდავს, რამდენი
   ასეთი ჩანაწერია.
3. **მსგავსება** — აღწერა (+ სახელი) → embedding ლოკალური მრავალენოვანი მოდელით.
   ქულა = 0.7 × სიუჟეტის cosine მსგავსება + 0.3 × ჟანრების Jaccard. (წონები ჩემი საწყისი არჩევანია.)
   ფილმები და სერიალები **ცალ-ცალკე** ითვლება — ფილმის მეზობლები მხოლოდ ფილმებია.
   თითო ჩანაწერზე ინახება ტოპ-30 მეზობელი ქულებით.
4. **ექსპორტი** — კომპაქტური JSON ფაილები აპისთვის, ფილმები და სერიალები ცალკე; მსუბუქი
   ინდექსი (ძებნისთვის) გამოყოფილია მძიმე ნაწილისგან (აღწერები), რომ ტელეფონზე სწრაფად გაიხსნას.

**განახლება** (ჩემი გადაწყვეტილება): მონაცემი არის სურათი (snapshot) გაშვების მომენტისთვის.
ავტომატური განახლება არ არის. ახალი ფილმების დასამატებლად ხელით ეშვება იგივე pipeline:
ჩამოტვირთავს მხოლოდ ახალ გვერდებს, embedding-ს ითვლის მხოლოდ ახლებისთვის (ძველები ქეშშია),
მეზობლებსა და ექსპორტს თავიდან აგენერირებს მთლიანად. ექსპორტს აქვს ვერსია, რომ service
worker-მა ტელეფონზე ძველი მონაცემი ახლით ჩაანაცვლოს. sitemap-იდან გამქრალი გვერდები
ექსპორტიდან ამოდის.

### 2. აპი (სტატიკური, build-ის გარეშე ან მინიმალურით)

- **ზედა ნაწილი:** გადამრთველი "ფილმები / სერიალები"; ძებნის ველი (სახელი ქართულად ან
  ინგლისურად, ან ID); ჟანრების ფილტრი (რამდენიმეს არჩევა).
- **საწყისი ეკრანი** (არაფერია არჩეული): ძებნის/ფილტრის შედეგების სია; არჩევა ხსნის გრაფს.
- **გრაფი:** არჩეული ფილმი ცენტრში, ირგვლივ N უახლოესი მეზობელი (სლაიდერი 5–30, საწყისი 12).
  კავშირის სისქე/სიგრძე = მსგავსების ქულა; კვანძის ფერი = მთავარი ჟანრი. მეზობლებს შორისაც
  იხატება კავშირი, თუ ისინი ერთმანეთის ტოპ-სიაში არიან (ამით ჩანს კლასტერები, როგორც graphify-ში).
  კვანძის გადათრევა, zoom, pan.
- **კვანძზე დაჭერა:** გვერდითი პანელი (ტელეფონზე — ქვედა ფურცელი): პოსტერი, სახელი (ქა/ინგ),
  წელი, ჟანრები, აღწერა, ღილაკი "უყურე gemovie.tv-ზე" (ახალ ტაბში), ღილაკი "ამის ირგვლივ
  აჩვენე" (გრაფი ამ ფილმზე გადადის). უკან დაბრუნება ბრაუზერის back-ით.
- **ჟანრის ფილტრი გრაფში:** ფილტრი ავიწროებს ძებნის სიას; გრაფში შეუსაბამო მეზობლები
  მკრთალდება (არ ქრება).
- **PWA:** manifest + service worker; ყენდება მთავარ ეკრანზე, აპის გარსი და უკვე ჩატვირთული
  მონაცემები ხაზგარეშეც მუშაობს. პოსტერები იტვირთება პირდაპირ gemovie.tv-ის სერვერიდან (ინტერნეტით).
- ინტერფეისის ენა: ქართული. ნათელი და მუქი თემა სისტემის მიხედვით.

## რა რჩება ამშენებელზე

- კონკრეტული embedding მოდელი. პირობა: უფასო, ლოკალური, ქართულის მხარდაჭერით, 16 GB M1-ზე
