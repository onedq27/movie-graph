# ფილმების გრაფი

[gemovie.tv](https://gemovie.tv)-ის ფილმებისა და სერიალების „მსგავსების გრაფი“: ირჩევ ფილმს და
ხედავ მის ირგვლივ ყველაზე მსგავს ფილმებს (სიუჟეტითა და ჟანრით). კვანძზე დაჭერით იხსნება
აღწერა და ბმული საიტზე საყურებლად. ძებნა შეიძლება სახელით, ID-ით და ჟანრით; ფილმები და
სერიალები ცალ-ცალკეა.

აპი სტატიკურია (სერვერი არ სჭირდება) და ტელეფონზე აპლიკაციასავით ყენდება.

## ტელეფონზე დაყენება

გახსენი აპის ბმული: `https://<მომხმარებელი>.github.io/<რეპო>/`

**Android (Chrome):** მენიუ (⋮) → „Add to Home screen“ / „Install app“ („მთავარ ეკრანზე დამატება“ /
„აპის დაინსტალირება“).

**iPhone (Safari):** Share ღილაკი (კვადრატი ისრით) → „Add to Home Screen“ („მთავარ ეკრანზე
დამატება“). iPhone-ზე ეს მხოლოდ Safari-დან მუშაობს.

ერთხელ გახსნის შემდეგ აპის გარსი და უკვე ნანახი მონაცემები ინტერნეტის გარეშეც იხსნება.
პოსტერები gemovie.tv-დან იტვირთება, ამიტომ მათ ინტერნეტი სჭირდება.

## მონაცემების განახლება

მონაცემი არის სურათი გაშვების მომენტისთვის — ავტომატურად არ ახლდება. ახალი ფილმების
დასამატებლად, რეპოს ძირიდან:

```sh
python3 pipeline/scrape.py          # ჩამოტვირთავს მხოლოდ ახალ/აკლებულ გვერდებს
.venv/bin/python -m pipeline.run    # მსგავსება + ექსპორტი app/data/-ში
```

პირველ ჯერზე საჭიროა გარემო: `uv venv --python 3.12 .venv` და
`uv pip install --python .venv/bin/python -r requirements.txt`.

შემდეგ `app/data/` დააკომიტე და გაუშვი (`push`) `main`-ზე — საიტი თავისით განახლდება.
დაყენებული აპი ახალ მონაცემს მომდევნო გახსნაზე აიღებს (ინტერნეტით), ძველს კი წაშლის.
თუ თავად აპის კოდი შეიცვალა, ცვლილება გამოჩნდება მეორე გახსნაზე.

## ლოკალურად გაშვება

```sh
python3 -m http.server -d app 8765
```

და გახსენი <http://localhost:8765/>.

## გამოქვეყნება (GitHub Pages)

- რეპო საჯარო უნდა იყოს (უფასო გეგმაზე Pages მხოლოდ საჯარო რეპოდან მუშაობს).
- რეპოს Settings → Pages → „Build and deployment“ → Source: აირჩიე **GitHub Actions**.
- ამის შემდეგ `main`-ზე ყოველი `push` აქვეყნებს `app/` საქაღალდეს
  (`.github/workflows/pages.yml`).

## მსგავსება

როგორ ითვლება მსგავსება, რომელი მოდელია არჩეული და რატომ: [docs/similarity.md](docs/similarity.md).

## სტრუქტურა

- `pipeline/` — ჩამოტვირთვა, ამოღება, მსგავსება, ექსპორტი (Python).
- `app/` — თავად აპი; `app/data/` — მზა JSON, რომელსაც აპი კითხულობს.
- `app/sw.js`, `app/manifest.webmanifest`, `app/icons/` — PWA-ს ნაწილი
  (ხატულების თავიდან დაგენერირება: `python3 app/dev/make_icons.py`).
- `data/` — ნედლი ქეში და embedding-ები; რეპოში არ იდება.
